# 新規ドキュメント作成

$ARGUMENTS を元に、新しいドキュメントを作成してください。

## 作成手順

1. 適切なディレクトリを選択（docs/ 配下）
2. YAMLフロントマターを含むドキュメントを作成
3. テンプレートを参考に基本構造を作成
4. 更新履歴セクションを追加

## テンプレートの基本構造

```markdown
---
id: DOC-XXX-001
title: ドキュメントタイトル
status: draft
created: YYYY-MM-DD
updated: YYYY-MM-DD
author: <作成者>
related: []
---

# ドキュメントタイトル

このドキュメントは...

## セクション1

### サブセクション

---

## 更新履歴

| 日付 | 変更内容 | 担当者 |
|------|---------|--------|
| YYYY-MM-DD | 初版作成 | <作成者> |
```

## ドキュメントタイプ別のテンプレート参照

- **機能仕様**: `docs/feature-specs/_template.md` を参照
- **システム設計**: `docs/system-design/` 配下のファイルを参照
- **AI コンテキスト**: `docs/ai-context/` 配下のファイルを参照

## チェック項目

- [ ] YAMLフロントマターが完全
- [ ] 見出し階層が正しい（H1→H2→H3）
- [ ] 関連ドキュメントへのリンクがある
- [ ] AI最適化の構造化データ（YAMLブロック）が含まれている
