# ドキュメント品質チェック

$ARGUMENTS で指定されたドキュメントの品質をチェックしてください。

## チェック項目

### 1. フロントマター
- [ ] `id` が設定されている
- [ ] `title` が設定されている
- [ ] `status` が設定されている（draft/review/approved）
- [ ] `created` が設定されている
- [ ] `updated` が設定されている
- [ ] `author` が設定されている

### 2. 構造
- [ ] H1（#）は1回のみ使用
- [ ] 見出し階層が正しい（H2→H3→H4、スキップなし）
- [ ] 目次がある（長いドキュメントの場合）
- [ ] 更新履歴セクションがある

### 3. 内容
- [ ] プレースホルダーが残っていない（`<プロジェクト名>` 等）
- [ ] 日付が正しいフォーマット（YYYY-MM-DD）
- [ ] コードブロックに言語指定がある
- [ ] リンクが正しい（broken linkがない）

### 4. AI最適化
- [ ] YAMLコードブロックで構造化されている
- [ ] 曖昧な表現が少ない
- [ ] 用語が一貫している（glossary.mdと照合）

## 出力形式

チェック結果を以下の形式で報告してください：

```
## チェック結果: [ファイル名]

### 問題点
- [ ] 問題1: 説明
- [ ] 問題2: 説明

### 改善提案
- 提案1
- 提案2

### 総合評価
- スコア: X/10
- コメント: ...
```
