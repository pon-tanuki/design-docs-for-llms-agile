# 新規テンプレート追加

$ARGUMENTS を元に、新しいドキュメントテンプレートを作成してください。

## 作成手順

1. 適切なディレクトリを選択（templates/ 配下）
2. YAMLフロントマターを含むテンプレートを作成
3. プレースホルダーを適切に配置
4. 更新履歴セクションを追加

## テンプレートの基本構造

```markdown
---
id: DOC-XXX-001
title: ドキュメントタイトル
status: draft
created: YYYY-MM-DD
updated: YYYY-MM-DD
author: <作成者>
related: []
---

# ドキュメントタイトル

このドキュメントは...

## セクション1

### サブセクション

---

## 更新履歴

| 日付 | 変更内容 | 担当者 |
|------|---------|--------|
| YYYY-MM-DD | 初版作成 | <作成者> |
```

## チェック項目

- [ ] YAMLフロントマターが完全
- [ ] 見出し階層が正しい（H1→H2→H3）
- [ ] プレースホルダーが一貫している
- [ ] AI最適化の構造化データ（YAMLブロック）が含まれている
