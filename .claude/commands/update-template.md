# テンプレート更新

$ARGUMENTS で指定されたテンプレートを更新してください。

## 更新時の必須作業

1. **フロントマターの更新**
   - `updated:` を今日の日付に変更
   - 必要に応じて `status:` を更新

2. **更新履歴の追記**
   - 変更内容を更新履歴テーブルに追加

3. **内容の更新**
   - 指示された変更を適用

## 更新履歴の記入例

```markdown
| YYYY-MM-DD | 〇〇セクションを追加 | <担当者> |
```

## 変更種別

- `追加`: 新しいセクションや内容を追加
- `修正`: 既存内容の誤りを修正
- `更新`: 既存内容を最新化
- `削除`: 不要な内容を削除
- `リファクタ`: 構成変更（内容は同じ）
